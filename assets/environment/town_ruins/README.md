# Разорённый город

Стилизованные брусчатка и грязная дорога с колеями — `textures/`, промпты там же. Меши original: adult_body (неподвижный взрослый силуэт в порванном пальто), hanging_body (тот же силуэт с верёвкой), rubble (обломки камня/дерева). Никакой логики врага, награды или звука смерти у этих моделей нет.

Размещаются через town_ruin_dressing.gd: пять груд по десять тел, шесть подвешенных фигур с металлическими подвесами, завалы и три покосившихся прилавка. Коллизии груд и препятствий участвуют в запекании навигации. Отдельные тела не занимают игровые пулы трупов и не удаляют трупы настоящих врагов. Модели тел — упрощённая геометрия для чтения с игровой камеры, не детально скульптированные персонажи.

Расширение карты: пять площадей/дворов и обходные переулки по обе стороны обязательной учебной двери. 12 пачек по 5 + босс = 61 враг; четыре добавленные пачки стоят в боковых районах. HP и награды обучения прежние.

Четыре покрытия пола собраны по единой сетке 2×2 м: плиты, брусчатка основной дороги, грунтовые переулки, грубый камень площадей. Ни одна ячейка не рисуется дважды; пересекающиеся коллайдеры прежних прямоугольников остаются только для физики. В момент текущего прохода карта содержит 2073 уникальные ячейки (~8292 м²).
