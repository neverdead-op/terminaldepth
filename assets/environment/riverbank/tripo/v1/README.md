# Модели автора из Tripo

Подключены шесть моделей из авторского архива `модели.rar`. В каждой подпапке лежат игровой GLB и три карты: albedo, normal, metallic_roughness.
Названия: RB_ROCK_BANK_A, RB_ROCK_SMALL_B, RB_WALL_STRAIGHT_4M, RB_WALL_BROKEN_4M, RB_PILLAR_CORNER, RB_ARCH_GATEWAY.
Концепты, размеры и подключение: `docs/art_direction/riverbank/tripo/README.md`.
Оригинальные наборы проекта не перезаписывать; новую модель назначать в поле Model Scene соответствующего модуля из `assets/environment/riverbank/modules/`.

Исходные OBJ/MTL/PNG сохранены в `art_source/riverbank/tripo_v1/модели/` под `.gdignore`. Подготовка — `tools/prepare_riverbank_tripo.py`; отчёт — `asset_report.json`.
В исходных 4096 PNG содержимое находится в прямоугольнике (0,2048)–(2048,4096); для игровых копий извлечён этот квадрат 2048×2048 без изменения оригиналов. Проверка прямоугольника выполняется для каждой карты. Не применять это автоматически к другим источникам проекта.
Оси стен и арки повёрнуты на 90° вокруг Y, чтобы длина шла по X. У каждой OBJ есть одна неиспользуемая нечисловая вершина; она не переносится в GLB, все исходные треугольники сохранены. Текстуры остаются внешними: переносить GLB вместе с PNG из его папки.
