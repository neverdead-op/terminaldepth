# Red huntress v1

Игровая героиня из предоставленного пользователем `MAIN HERO ASSET/RIP0.obj`.
Одна из шести фигур, 56 219 треугольников, 68 костей, внешние PBR PNG 4096².
Торчащий шарф удалён, воротник сохранён. Физика ткани отложена и не подключена.
Переносить GLB и все три PNG вместе. Подключение: `assets/characters/huntress_player.tscn`.

Исходники Blender: `art_source/red_huntress_v1`.
Анимации: `assets/animations/huntress_shooter.tres`.
Сборка, проверки и ограничения: `docs/HUNTRESS_PLAYER.md`.
