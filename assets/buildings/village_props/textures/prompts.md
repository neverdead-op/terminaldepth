# Wicker texture generation

Built-in imagegen, original simplified painted base color. Other props reuse stylized brick, sandstone and oak assets already in the project.

Single square seamless tileable BASE COLOR texture for a stylized hand-painted Victorian wicker basket, match broad graphic painted shapes in reference. Chunky flat basket weave in muted desaturated ochre-brown, dark brown spaces between broad interwoven strips. Only 10 large woven strips across, broad simple alternating over-under pattern. Two calm flat color patches per strip, sparse tapered charcoal edges. No photography, no realistic fiber hairs, no micrograin, no fine noise, no scratches. Flat neutral uniform diffuse illumination with NO cast shadows, no directional light, no vignette, no perspective, no specular highlights. Full frame swatch only, not a rendered basket, not an illustration scene, no text, labels or border. Seamlessly repeat all sides.
