# Компактный интерфейс Terminal Depth

Автор утвердил подключение 15 октября 2026: чёрный состаренный металл, тонкие бронзовые края, минимум золота. Две небольшие группы HUD внизу; центр свободен. Энергощит накладывается на ту же полосу здоровья.

## Готовые изображения

`assets/ui/gothic_v1/` содержит четыре PNG с настоящим альфа-каналом:

| Файл | Размер | Назначение |
|---|---|---|
| hud_plate.png | 2172 × 724 | Компактные панели, предметные слоты, вкладки |
| window.png | 1024 × 1536 | Инвентарь, навыки и торговля |
| socket.png | 1254 × 1254 | Круглое гнездо с прозрачным центром |
| tooltip.png | 1448 × 1086 | Подсказки и карточка товара |

У панелей прозрачное внешнее поле, внутри — непрозрачный чёрный металл для читаемости. Текст, предметы и показатели рисуются игрой поверх рамок. Масштабирование из девяти частей сохраняет уголки; координаты исходных областей — `scripts/ui_style.gd`. Исходные PNG сохранены без изменения пикселей.

Метод генерации — встроенный image_gen, режим прозрачного фона. Концепты всех четырёх экранов и точные промпты для концептов и деталей сохранены в `docs/ui_concepts/v1/` (`*_prompt.txt`). Концепты служат ориентиром; в игре используются отдельные рамки с живыми данными.

## Проверка

- F5 — игра с новым HUD. Три оружия 1–2–3; активное выделено.
- I / Tab — экипировка и сумка. Два больших оружия по краям, пистолет внизу, броня и шлем в центре.
- K — отдельные навыки и модули. Выбор модуля в сумке переводит в это окно. У автомата граната имеет независимые гнёзда.
- На геймпаде открыть инвентарь и переключать четыре вкладки LB/RB; A — действие, B — назад.
- У торговца — купить, продать, разбор; в карточке выбранного товара реальные свойства и цена.

Параметры ширины HUD, отступы и цвета здоровья/щита доступны в Inspector у `hud_ref.gd`.

`scenes/tools/test_ui.tscn` проверяет три слота, разделение окон, установку модуля, вкладки геймпада, фактическое списание/начисление золота при покупке/продаже, прозрачность рамок. `-- --capture` сохраняет четыре снимка `docs/screens/ui_*.png`. Тест использует Game.start_test и не пишет настоящее сохранение.
