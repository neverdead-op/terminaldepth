# Реалистичная экипировка первого акта

30 отдельных прозрачных изображений созданы встроенным ImageGen: 24 предмета защиты и 6 единиц оружия. Игровые PNG находятся в `assets/icons/act_one_realistic/`. Точные запросы сохранены в `prompts.json`.

Окончательный ориентир автора — мрачный реализм Path of Exile 2, викторианская готика. Броня — тёмная кожа и сталь; чистый энергощит — светлая кожа, серебро и голубоватые стеклянные излучатели; гибрид — бордовая кожа, сталь и излучатели. В каждой группе по два уровня шлемов, нагрудников, перчаток и ботинок.

Оружие: простой и улучшенный коломёты (`rifle`, `carbine`), два дробовика (`shotgun`, `pump_shotgun`), два серебряных пистолета (`plasma_cutter`, `plasma_cutter_mk2`). Технические ID оставлены для совместимости. Дополнительный существующий `pistol` не удаляется.

Оба коломёта переработаны в арбалеты с видимыми плечами, тетивой и нижним барабаном коротких кольев. Первый дробовик — короткая двустволка, первый серебряный пистолет — компактный самозарядный пистолет. Второй дробовик и второй пистолет сохранены по выбору автора. Запросы правок: `revision_prompts.json`.

Новые названия всех 30 предметов находятся в `scripts/item_art_names.gd`, английские переводы — в `data/lang/en.gd`. GearItem применяет имя к копии базы, не меняя исходный справочник и ID; загруженное описание оружия получает то же художественное имя. Старые сохранения получают новые имена при восстановлении предметов. Редкие и уникальные вещи сохраняют собственные имена.

На изображениях защиты общий `UiIcons.draw_item_picture` показывает знак щита для брони, шестигранник с молнией для энергощита и оба знака для гибрида. В подсказке есть строка типа защиты. Знаки определяются базовым типом защиты, не случайными свойствами.

Характеристики, модели в руках, снаряды и навыки не меняются. В частности, рисунок коломёта сам по себе не добавляет деревянные колья в бою, а рисунки серебряных пистолетов не меняют свойства прежних баз.

`UiIcons.texture` выбирает новые изображения вместо прежних путей `act_one`; старые PNG сохранены. Все потребители `draw_item_picture` и изображения оружия HUD используют общий выбор.

Проверка: открыть `scenes/tools/test_equipment_catalog.tscn` и нажать F6. Галерея показывает весь набор; с `-- --capture` сохраняет реальный кадр в `docs/screens/equipment_catalog.png`. Кампания не запускается, сохранение не записывается.

Проверено в настоящем игровом интерфейсе через `test_inventory_art.tscn`: экипировка, перенос модулей, вкладки и пауза работают. Кадр D3D12 с новыми предметами и знаками защиты: `in_game_inventory.png`. Профиль теста изолирован в `ztest/realistic_icons_profile`; настоящий забег не записывался. Прежние сообщения очистки текстур D3D12 при выходе остаются.

Торговля отдельно проверена временным `ztest/test_realistic_trade.tscn`: покупка, продажа, списание/возврат золота и страницы ассортимента прошли; кадр — `in_game_trade.png`. Использована торговая часть `test_ui`, без его устаревшей подготовки третьего оружейного слота (полный старый тест останавливается на этом ожидании).
