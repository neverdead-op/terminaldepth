## Промпт нового листа

Единый прозрачный лист 6 × 5 простых игровых иконок в gothic industrial sci-fi: тёмная сталь, сдержанная бронза, голубая энергия.
Разные силуэты оружия: компактный Г-образный резак / резак с вилочной головкой; короткая двустволка / длинный помповый дробовик;
компактный автомат / длинный автомат с отдельным прикладом. Стволы вправо.
Броня: простой патрульный комплект / угловатый тяжёлый комплект с высоким шлемом и широкими наплечниками.
Гибрид: округлый технический комплект с небольшими излучателями / угловатый боевой комплект с Т-образным визором и ромбовидным реактором.
Сохранить удачное направление чистого ЭЩ: светлые тонкие панели, круглые голубые ядра, светящиеся направляющие.
Без текста, рамок и фона, с промежутками для разрезки.
