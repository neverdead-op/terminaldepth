# Рамки здоровья

`scripts/health_bar_frame.gd` подключает сгенерированные PNG из `assets/ui/gothic_v4/health_frames/`:

- `overhead_frame_v1.png` — прозрачная рамка над игроком и врагами; общий QuadMesh на размер и материал на приоритет отрисовки.
- `mob_frame_v2.png` — компактная верхняя полоса обычной цели (заливка 190×5).
- `boss_frame_v2.png` — украшенная полоса босса (заливка 330×8). Выбор по `guards_exit` / группе `bosses`, не по редкости.
- `target_panel_v1.png` сохранён как прежний рисунок, в верхней панели больше не используется.

Прозрачные поля исключены через AtlasTexture, исходные PNG сохранены целиком. Отверстия рамок совмещены с существующей заливкой. Мировая рамка наследует поворот и видимость всей полосы; она не масштабируется вместе с оставшимся здоровьем. Правила скрытия, щита, выбора цели и урона сохранены. Размеры верхних полос настраиваются через `bar_size` и `boss_bar_size`. Имя и уровень находятся над рамкой в отдельных областях; имя выровнено по центру полосы. Текст меньше, с мягким тиснением и тенью. Длинные названия уменьшаются, при необходимости завершаются многоточием.

В игре: полосы видны над персонажами; после попадания во врага появляется верхняя панель цели. Проверка без сохранений: `res://ztest/hp_frames/test.tscn` — три значения здоровья, повороты, скрытие пустой/полной полосы, совместное использование меша, реальный кадр `ztest/hp_frames/in_game.png`. Этот тест — локальная диагностика, не часть кампании.

Проверка двух вариантов: `ztest/hp_compact/test.tscn`, кадры `mob.png`, `rare_long.png`, `boss.png` в той же папке. Проверяются выбор обычного/боссового рисунка, редкость, длинное русское имя и исчезновение панели по таймеру. Изолированный тест использует `Game.testing`, сохранения не записывает. Промпты новых PNG — `assets/ui/gothic_v4/health_frames/PROMPTS_v2.md`.
