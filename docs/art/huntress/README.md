# Охотница — ракурсы v1

`huntress_turnaround_v1.png` — сгенерированный встроенным ImageGen лист из шести ракурсов по референсу автора: фронт, оба профиля, спина и два вида в три четверти. Это художественный референс для моделирования, не готовая 3D-модель и не геометрически точный чертёж. При моделировании нужно согласовать асимметричные ремни, кобуру и разрывы ткани между видами.

Источник: `codex-clipboard-6fadc66f-f3bd-489a-bc49-3d27fe79e7d3.png`, предоставлен автором.
