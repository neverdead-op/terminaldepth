# Предоставленный револьвер

`pistol/RIP0.obj` с исходным цветовым атласом подключён к `data/weapons/pistol.tres`.
9 935 треугольников, длина 0,38 м; UV и геометрия сохранены без упрощения.
Рукоять — начало координат, ствол направлен по -Z. `MuzzleTip` отмечает центр
среза ствола. Никаких новых normal/ORM карт не создавалось.

Подготовка: Blender background `--python tools/prepare_supplied_pistol.py`, затем
импорт Godot. Игровая сцена: `assets/weapons/supplied_pistol/pistol_visual.tscn`.
Редактируемая копия: `art_source/supplied_pistol/pistol_game.blend` с `.gdignore`.
Исходные OBJ/PNG и прежняя модель пистолета сохранены.
Урон, темп, магазин, перезарядка и звук не менялись.
Обычный pistol доступен в первом акте и занимает один из двух оружейных слотов.
При загрузке он сохраняется пистолетом; миграция в резак оставлена для других
отложенных старых баз. Формат сохранений не менялся, проверка использует сериализацию
в памяти без записи реальных сохранений.

Револьвер уже выдан во втором слоте обычного `scenes/tools/level1_playtest.tscn`:
1 — автомат, 2 — револьвер, Q / колесо мыши / Y геймпада — переключение.
F7 восстанавливает оба оружия. При обычном старте кампании используется её
существующий стартовый выбор pistol; настоящую «Новую игру» для проверки не запускали.
В Demo и режиме Бога револьвер также выдан вторым оружием рядом с автоматом.
Проверено через `Game.start_test` без записи сохранений.

Сохранён отдельный просмотр уровня: `scenes/tools/supplied_pistol_level.tscn` → F6.
ЛКМ — выстрел, R — перезарядка, F7 — сброс. Это отдельный `Game.testing`:
выбирается второй слот того же комплекта. `-- --capture` проверяет модель,
точку дула и реальный выстрел с расходом патрона, кадр —
`docs/screens/supplied_pistol_level.png`. Проверка использует отдельный APPDATA.
