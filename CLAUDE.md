# Terminal Depth

Главные документы — читать их, а не искать по всему проекту:
- [AGENTS.md](AGENTS.md) — правила работы, действующие решения автора, проверки и сохранения.
- [PROJECT_MAP.md](PROJECT_MAP.md) — карта систем: какие файлы за что отвечают и где менять.

Перед правкой — нужный раздел PROJECT_MAP.md, затем только относящиеся к задаче файлы.
Прежняя длинная версия этого файла (sci-fi этап «Кербер-7») устарела; её можно найти в истории git.

## Как общаться с автором

- Автор игры — без опыта программирования. Общение на русском, простыми словами, без жаргона;
  новые понятия Godot пояснять кратко.
- Код пишет Claude целиком. Автор запускает игру и даёт обратную связь по ощущениям.
- После правок кратко говорить, что изменилось и как проверить (какую сцену запустить, какие кнопки нажать).
- Настраиваемые цифры выносить в `@export`, чтобы автор мог менять их в Inspector без кода.
- Автор может писать с телефона: тогда результат показывать скриншотами из игры (SendUserFile).
- «PoE» у автора — Path of Exile 2. Сборки (exe) не делать и не слать без просьбы.

## Ориентир для решений по уровням (GDC 2013)

Интересно перемещаться; не полагаться на слова; говорить «что», а не «как»; постоянно учить (одна-две
механики на этаж); удивлять; давать силу; лёгкое, среднее и сложное одновременно; ничего лишнего;
вызывать эмоции; строиться на механиках. Механики вводить постепенно, всё активное подсвечивать ярко.
