# Terminal Depth

3D top-down экшен с добычей, крафтом и прокачкой в духе Path of Exile 2. Викторианская готика.
Движок — **Godot 4.7** (Forward+, Jolt Physics), язык — GDScript.

## Как запустить

1. Установите [Godot 4.7](https://godotengine.org/download) (стандартная версия, не .NET).
2. Склонируйте репозиторий **с Git LFS** (один файл анимации больше 100 МБ хранится через LFS):
   ```
   git lfs install
   git clone <адрес репозитория>
   ```
3. Откройте `project.godot` в Godot. Первый импорт ресурсов занимает несколько минут.
4. F5 → «Новая игра» → SSF.

## Где что лежит

- `PROJECT_MAP.md` — карта систем: какие файлы за что отвечают.
- `AGENTS.md` — правила работы и решения автора.
- `scenes/`, `scripts/` — сцены и код; `data/` — оружие, модули; `assets/` — модели, текстуры, звуки.
- `scenes/tools/` — автотесты, например `test_ssf_village.tscn` (проверка первого уровня).

В репозиторий не входят исходники ассетов (сырые выгрузки моделей, архивы звуков, рабочие .blend):
они хранятся у автора локально.
